# Tiendas D2 - Módulo de Contacto y PQRS

Componente web interactivo y responsivo para el servicio al cliente de Tiendas D2.
Permite enviar consultas generales, PQRS, solicitudes de empleo y cotizaciones a proveedores.

## Tecnologías

- HTML5
- CSS3 (Grid/Flexbox)
- JavaScript (validación en el cliente)

## Estructura

- `index.html` - Página principal con el formulario
- `css/` - Hojas de estilo
- `js/` - Scripts de validación

## Uso

1. Abrir `index.html` en un navegador.
2. Completar el formulario con los datos solicitados.
3. Enviar la solicitud y verificar el mensaje de confirmación.

## Mantenimiento

- Los estilos están en `css/` y los scripts en `js/`, separados para facilitar cambios.
- Las validaciones de los campos están en el archivo JavaScript principal.
